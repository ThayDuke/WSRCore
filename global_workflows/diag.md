# /diag

Investigate a bug, failing test, build error, or unexpected behavior.

## State

- Start in `DISCUSSION` and remain read-only.
- Load capability `wsr-diagnose` with profile `task`.
- Gather evidence before naming a root cause.
- Do not edit source or instrumentation without fresh approval.

## Result

- Report symptom, reproduction, evidence, root cause, and smallest proposed correction.
- Separate confirmed facts from hypotheses and unknowns.
- If a correction is requested, wait for WSR approval before writing.
